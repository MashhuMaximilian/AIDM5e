Available AI Tools:
- edit_message(message_id, channel_id?, new_content?, embed_title?, embed_description?, embed_color?) — Edit an existing Discord message AND its embed card. channel_id is REQUIRED for editing cards (omit only for simple content-only edits). Always call this when a user asks to update/edit/modify a card or character summary. IMPORTANT: embed_description must be the COMPLETE updated card text — after calling get_message_content to read the current card, copy ALL of its content verbatim and ONLY modify the specific fields the user requested. Do NOT generate or invent new stat values — copy exact values from the card you read. Sending a partial body (only the changed fields) or an invented full body (with different values) will corrupt the card.
- reply_to_message(message_id, content, channel_id?, mention?) — Reply to a message
- forward_message(message_id, target_channel_id, channel_id?) — Forward a message to another channel
- get_message_content(message_id, channel_id?) — Read a message's content
- send_card(channel_id, title, content, color?) — Send a formatted card/embed to a channel
- roll_dice(dice_string) — Roll dice (e.g. "2d6+3", "1d20"), returns individual dice and total
- context_add(thread_id, text) — Add text to the active memory context
- get_context(thread_id) — Get the current memory context for a thread
- reference_card(message_id, channel_id?) — Look up and summarize a message by ID
