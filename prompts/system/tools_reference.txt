Available AI Tools:
- edit_message(message_id, channel_id?, new_content?, embed_title?, embed_description?, embed_color?) — Edit an existing Discord message AND its embed card. channel_id is REQUIRED for editing cards (omit only for simple content-only edits). Always call this when a user asks to update/edit/modify a card or character summary. embed_description must be the FULL updated card text — include all existing card content with only the changed fields updated. Do NOT call get_context or any other function between get_message_content and edit_message.
- reply_to_message(message_id, content, channel_id?, mention?) — Reply to a message
- forward_message(message_id, target_channel_id, channel_id?) — Forward a message to another channel
- get_message_content(message_id, channel_id?) — Read a message's content
- send_card(channel_id, title, content, color?) — Send a formatted card/embed to a channel
- roll_dice(dice_string) — Roll dice (e.g. "2d6+3", "1d20"), returns individual dice and total
- context_add(thread_id, text) — Add text to the active memory context
- get_context(thread_id) — Get the current memory context for a thread
- reference_card(message_id, channel_id?) — Look up and summarize a message by ID
